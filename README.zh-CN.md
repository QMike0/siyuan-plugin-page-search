# 思源笔记页内搜索与替换

[English](https://github.com/QMike0/siyuan-plugin-page-search/blob/main/README.md) | [简体中文](https://github.com/QMike0/siyuan-plugin-page-search/blob/main/README.zh-CN.md)

面向思源笔记当前打开文档的搜索与替换插件。支持关键字、正则表达式、块类型筛选、离屏内容处理，以及单处替换和全部替换。

## 快速开始

1. 在思源笔记「集市 → 已下载」中启用插件。
2. 点击顶栏图标，或按 `Ctrl+F`（macOS：`⌘F`）打开搜索条。
3. 输入关键词后使用 `Enter` / `Shift+Enter` 在命中之间移动。
4. 点击替换行左侧的展开按钮，或按 `Ctrl+H`（macOS：`⌘H`）打开替换输入框。

## 页内搜索

页内搜索只针对当前编辑器对应的文档工作。搜索结果会在编辑器中高亮，当前命中使用橙色标记，其余命中使用黄色标记。

![页内搜索](https://cdn.jsdelivr.net/gh/QMike0/pic_bed@main/img/image-20261016002506695.png)

### 搜索方式

搜索条中的方法菜单提供两种模式：

* **关键字**：按普通文本匹配。文字查询会忽略首尾空白，并同时尝试去除关键词内部空白的变体；不进行简繁、全半角或 NFC 转换。
* **正则表达式**：使用 JavaScript 正则规则。正则替换支持 `$1`、`$&` 等替换模板。

其他常用选项：

* **Aa**：区分大小写。
* **整词**：按空白、英文标点和常用中文标点判断边界。
* **Aa\***：替换时尽量保持命中内容的大小写形态；正则模式下不可用。
* **选区内**：只搜索当前文字选区或块选范围。

### 搜索范围

![image-20261016002022803](https://cdn.jsdelivr.net/gh/QMike0/pic_bed@main/img/image-20261016002022803.png)

- 齿轮菜单中的「是否搜索」用于控制块类型。可分别开关：

  * 文档标题、图片标题、行内备注；
  * 段落块、标题块（H1–H6）、无序/有序/任务列表块；
  * 公式块、普通代码块、Mermaid、flowchart；
  * 表格块、数据库块、引述块、提示块、超级块、页签块、思维导图块；
  * 嵌入块、HTML 块和自定义块。

  其中：

  - 「图片标题」指图片下方的图片标题文本，不是思源窗口或文档页签栏中的标题；
  - 页签块会搜索已打开和未打开的页签内容。搜索结果位于未打开页签时，插件会先切换到对应页签再定位；
  - 数据库按当前已经显示的行数建立搜索范围。超出当前显示数量的行不会计入结果；点击数据库的「加载更多」后，插件会重新索引新增显示的行。

- 「限制搜索」可以进一步临时限定行级元素类型，例如链接、加粗、代码、行内公式或行内备注。启用限制后，计数、跳转和替换范围都会同步收窄；关闭搜索窗口后，这些临时限制会清除。在「限制搜索」中选定某类型行级元素且搜索框为空时，可预览采用该类元素的全部关键词。

- 「折叠块内容」决定是否搜索非标题折叠块中的隐藏内容。开启后，符合搜索范围的折叠内容、思维导图折叠子节点内容仍可参与匹配；关闭后，这些隐藏内容不计入结果。

- 对于未加载、折叠或暂时不在屏幕中的内容，插件会优先使用思源能够提供的源数据进行匹配，不要求先把整篇文档滚动到屏幕上。若当前运行环境无法查询某部分未加载内容，搜索结果会标记为不完整。

### 搜索结果列表、搜索历史与其他

* 匹配计数闪烁时表示处于搜索匹配状态
* 点击匹配计数可以打开结果列表，每条结果显示命中附近的上下文。
* `Enter` 跳到下一个命中，`Shift+Enter` 跳到上一个命中，`Esc` 关闭搜索条。
* 结果项右侧显示所在块的类型图标，同类只显示一次，最多显示三个，超出时可悬浮省略号展开全部图标。标题块、列表块、代码块只显示大类图标，右键可从当前结果实际存在的小类中选择。点击图标可以临时按块类型筛选，多个类型可以组合；点击「清除筛选」恢复全部结果。
* 搜索历史按文档保存，在搜索框中按 `↑` / `↓` 可以切换历史关键词。
* 桌面端可以拖动计数区移动搜索面板，再次点击顶栏图标可以恢复默认位置。
* 打开搜索条时已有选区只会预填关键词，不会自动开启「选区内」。

## 页内替换

页内替换与页内搜索共用当前搜索结果，但写入规则不同。替换前会重新核对目标内容，避免搜索期间文档发生变化后误改内容。

![页内替换](https://cdn.jsdelivr.net/gh/QMike0/pic_bed@main/img/image-20261016002533227.png)

### 替换当前命中

点击「替换」只处理当前命中，然后移动到下一项。当前命中属于只读内容、跨越复杂格式，或已经发生变化时，插件会提示并跳过，不会强行写入。

### 全部替换

点击「全部替换」会先显示本次范围、可替换数量和将跳过的数量。确认后，插件会准备所有目标并尽量合并为一次思源事务：

* 结果仍在索引或范围不完整时，不会直接执行全部替换；
* 目标内容在准备期间发生变化时，会取消提交并刷新结果；
* 已加载、离屏、折叠或需要从思源源数据读取的块，使用同一套替换规则；
* 内容块替换通常支持思源的 `Ctrl+Z` / `Ctrl+Y` 撤销重做。

### 可以替换与只能搜索

通常可以替换：

* 普通可编辑块中的文本；
* 图片标题文本；
* 行内备注；
* 页签块、思维导图块及其可写源文本；
* 位于离屏、折叠或未加载区域、且能够取得完整源数据的文本。

只支持搜索和高亮，不支持替换的内容包括：

* 文档标题；
* 数据库内容；
* 嵌入块中的内容；
* 公式、渲染后的 Mermaid 和 HTML 块文本；
* 插件渲染的自定义块；
* 富文本表格单元格（带有 `data-sy-table-cell-rich` 特殊存储结构的单元格）；普通表格单元格中的普通文本支持替换；
* 页签块的页签标题；
* 跨越复杂标记、只读区域或无法确认原文的命中。

「全部替换」会把这些内容计入跳过数量，并在确认提示中说明。

## 发布与只读模式

在发布服务、导出预览或文档只读模式下仍可搜索和高亮，但替换按钮会被禁用。搜索范围开关可以在当前会话中临时生效，但不会写入配置。

## 调试日志

在思源「设置 → 集市 → 已下载 → 本插件设置」中开启「调试日志」，可在控制台查看搜索、索引、跳转和替换诊断信息，日志前缀为 `[page-search]`。默认只记录警告和错误；如果看不到调试信息，请在控制台启用 Verbose（详细）级别。

## 开发相关

1. 安装 Node.js 与 pnpm。
2. 在仓库根目录执行 `pnpm i`。
3. `pnpm run dev` 启动开发构建；`pnpm run build` 生成 `package.zip`。
4. `pnpm run smoke:shared` 运行共享匹配冒烟测试。
